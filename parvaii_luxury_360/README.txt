PARVAII LUXURY PRODUCT VIEWER

Open index.html in Chrome. No build or server required. Fonts load from Google when online; fallback fonts work offline.

Interactions: drag left/right, scroll to zoom, 360 View toggles automatic spin, thumbnails switch sides and open detail images.

IMPORTANT: This is a rotating two-sided image illusion, not a true 3D mesh or GLB. Side views will look flat. Back image is a generated interpretation and should be verified against the actual product.

To use other products, replace assets/front.png and assets/back.png with transparent images of the same size and alignment.
